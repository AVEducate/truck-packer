# Truck Packer

A free AV truck-packing puzzle game by [AV Educate](https://aveducate.com) for the AV community.
101 levels: floor loads, stacking, tipping and pockets, offloading at the venue, and a final exam with a certificate.

Play: https://games.aveducate.com/truck-packer/

Designed for a laptop or desktop with a keyboard and mouse. Progress saves in your browser; use SAVE CODE in Level Select to move it to another device.
