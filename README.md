# Truck Packology

Truck Packology is a free AV truck-packing game by [AV Educate](https://aveducate.com) for the AV community.
Campaign: 100 levels (floor loads, stacking, tipping and pockets, offloading at the venue) and a final exam for the Truck Packing Fundamentals certificate. Endless Tour: keep the trucks rolling.

Play: https://games.aveducate.com/truck-packology/

Designed for a laptop or desktop with a keyboard and mouse. Progress saves in your browser; use SAVE CODE in Level Select to move it to another device.
